Parallel by Default

Standardmäßig parallel

>> parallel pipeline operator and ai_batch process hundreds of texts in parallel. Native goroutines, Future auto-resolution, rate limiting. No async/await, no Promise.all.

>> Parallel-Pipeline-Operator und ai_batch verarbeiten hunderte Texte parallel. Native Goroutines, Future-Auflösung, Rate-Limiting. Kein async/await, kein Promise.all.

ai_rate_limit 10
texts: read_lines "articles.txt"
results: ai_batch "Summarize" texts

Single Binary

Einzelne Binary

One ~10 MB file. No venv, no pip, no npm, no Docker. Compile once, deploy to Linux, macOS, Windows, Raspberry Pi. Or run directly in the browser via WASM.

Eine ~10 MB Datei. Kein venv, kein pip, kein npm, kein Docker. Einmal kompilieren, überall deployen. Oder direkt im Browser per WASM ausführen.

# Build once

# Deploy everywhere

./pipe.exe script.pipe     # Windows
